# Quick Start Guide - My Custom Theme

Get up and running with My Custom Theme in 5 minutes!

## 🚀 Installation (2 minutes)

### Step 1: Download & Compress
```bash
cd /home/user/WorkLog
zip -r my-custom-theme.zip my-custom-theme/
```

### Step 2: Upload to WordPress
1. WordPress Admin → **Appearance → Themes → Add New**
2. Click **Upload Theme**
3. Choose `my-custom-theme.zip`
4. Click **Install Now** → **Activate**

✅ Theme installed!

---

## 🎨 Create Your First Page (3 minutes)

### Step 1: Create a Page
1. WordPress Admin → **Pages → Add New**
2. Title: "Home" (or anything you like)

### Step 2: Add Blocks
1. Scroll down to **Page Builder** section
2. Click **Add Block**
3. Choose **Hero Block** → Click it
4. Click the ✏️ **Edit** button
5. Change title to: "Welcome to My Website"
6. Change subtitle to: "Build amazing pages with ease"
7. Click **Save Settings**

### Step 3: Add More Blocks
1. Click **Add Block** again
2. Choose **Icon Box** → Click it
3. The default icons and text appear
4. Click **Edit** to customize (optional)

### Step 4: Add a Call-to-Action
1. Click **Add Block**
2. Choose **Button** → Click it
3. Click **Edit**
4. Button text: "Get Started"
5. URL: "#contact" (or any URL)
6. Click **Save Settings**

### Step 5: Publish!
1. Click **Save Layout** (in Page Builder)
2. Click **Publish** (WordPress publish button)
3. Click **View Page** to see your creation!

🎉 **Your first page is live!**

---

## 🎨 Customize Theme Colors (1 minute)

1. WordPress Admin → **Appearance → Customize**
2. Click **Theme Settings**
3. Click **Primary Color** → Choose your brand color
4. Changes preview instantly!
5. Click **Publish**

## 🔧 Common Tasks

### Change Block Order
- Drag the **☰** handle on any block
- Drop where you want it

### Duplicate a Block
- Click the **📋** button on any block
- Instant copy appears below

### Delete a Block
- Click the **🗑️** button
- Confirm deletion

### Edit Block Settings
- Click the **✏️** button
- Modify settings
- Click **Save Settings**

### Upload Images
- In Image or Gallery block
- Click **Select Image**
- WordPress Media Library opens
- Choose or upload image

## 💡 Pro Tips

### Tip 1: Use Hero for Headers
Start every page with a Hero block for professional headers.

### Tip 2: Feature + Icon Box Combo
Use Feature List for detailed features, Icon Box for quick overview.

### Tip 3: Save Time with Duplicate
Instead of adding similar blocks, duplicate and edit!

### Tip 4: Test on Mobile
Always preview your page on mobile (right-click → Inspect → Mobile view).

### Tip 5: Custom Blocks
Use Custom HTML block for widgets, embeds, or anything special.

## ❓ Quick Troubleshooting

**Problem**: Can't see Page Builder
- **Solution**: Make sure you're editing a **Page**, not a **Post**

**Problem**: Blocks not saving
- **Solution**: Click "Save Layout" before publishing

**Problem**: Images too large
- **Solution**: Use JPG format, optimize before upload

**Problem**: Drag and drop not working
- **Solution**: Refresh page, check browser console for errors

**Problem**: Theme looks broken
- **Solution**: Go to Settings → Permalinks → Save (no changes needed)
