## 📦 Available Blocks

### Content Blocks (7)

#### 1. Text Block
- Rich text content with HTML support
- Alignment options (left, center, right)
- Support for headings, paragraphs, lists
- Blockquotes and code formatting
- Ideal for: Articles, blog content, descriptions

#### 2. Button Block
- Customizable button text and URL
- Three style variations:
  - Primary (solid background)
  - Secondary (alternate color)
  - Outline (transparent with border)
- Open in new tab option
- Hover animations
- Ideal for: CTAs, navigation, links

#### 3. Testimonial Block
- Customer quote display
- Author name and role
- Styled quotation marks
- Background highlighting
- Ideal for: Social proof, reviews, endorsements

#### 4. Pricing Table Block
- Multiple pricing plans in a grid
- Customizable plan features
- Featured plan highlighting
- Call-to-action buttons
- Responsive columns
- Ideal for: SaaS pricing, product tiers, services

#### 5. Icon Box Block
- Grid of icon-based features
- Emoji or text icons
- Title and description
- Hover effects
- Responsive layout
- Ideal for: Features showcase, benefits, services

#### 6. Feature List Block
- Vertical list of features
- Icon + title + description format
- Clean, organized layout
- Icon animations on hover
- Ideal for: Product features, specifications, benefits

#### 7. Newsletter Block
- Email signup form
- Customizable heading and description
- Styled input and button
- Form action URL configuration
- Gradient background
- Ideal for: Email capture, subscriptions, lead generation

### Media Blocks (4)

#### 8. Image Block
- Media library integration
- Alt text for SEO
- Optional caption
- Rounded corners option
- Responsive sizing
- Lazy loading
- Ideal for: Photos, graphics, featured images

#### 9. Video Block
- YouTube video support
- Vimeo video support
- Self-hosted video support
- Automatic embed conversion
- Responsive 16:9 ratio
- Ideal for: Tutorials, demos, presentations

#### 10. Gallery Block
- Multiple images in grid
- 2, 3, or 4 column layouts
- Lightbox functionality
- Hover zoom effects
- Responsive design
- Ideal for: Portfolios, product showcases, photo albums

#### 11. Map Block
- Google Maps embed support
- Custom map service support
- Adjustable height
- Responsive iframe
- Ideal for: Contact pages, locations, directions

### Layout Blocks (1)

#### 12. Hero Block
- Full-width header section
- Large title and subtitle
- Call-to-action button
- Gradient background
- Responsive text sizing
- Ideal for: Page headers, landing pages, banners

### Advanced Blocks (1)

#### 13. Custom HTML Block
- Insert custom HTML code
- Scoped CSS styling
- Sandboxed JavaScript
- Real-time preview
- Ideal for: Embeds, custom widgets, advanced layouts
